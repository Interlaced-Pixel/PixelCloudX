A SMALLER DISTANCE TO PLAY

Built around the game.

01 / INSTANT LIBRARY

Start with your catalogue.

Saved game metadata and artwork appear first. Background refreshes quietly bring in new and changed titles, with visual markers you can review.

02 / NATIVE CONTROLS

Controller. Keyboard. Voice.

Use macOS Game Controller input or the keyboard gamepad. Command-M toggles your microphone, with its status always visible in the overlay.

03 / YOUR SETUP

A picture that fits.

Choose source, 16:9, 16:10, 4:3, or 21:9 presentation. Adjust fit, crop, volume, input, and Xbox preferences in persistent native Settings.

STAYS UP TO DATE

Updates, without losing
your place.

Sparkle checks the signed Interlaced Pixel update feed. Active game sessions postpone update checks and installation. You decide whether downloads happen automatically.

Before you download

PixelCloudX uses private Xbox web-client endpoints. Service availability and compatibility can change. An eligible Microsoft account, supported region, and any required subscription or game ownership are needed.

This initial release is locally signed and is not notarized by Apple. macOS may block a downloaded copy. The public source is available to inspect and build in Xcode.

PixelCloudX is an independent project, unaffiliated with Microsoft or Xbox. Microphone transport is implemented; remote voice-chat audibility still needs verification.
